# 项目摄像头工作区实施计划

用户已批准方案与完成后生产部署。仅 gooes，orange 只读且本轮无需变更。

1. 后端按项目数据库分页，支持已绑定／未绑定／全部与项目状态筛选，保留租户、项目权限；准确汇总设备数量和状态。展开设备使用独立分页接口，兼容小程序原接口。
2. 删除全局添加，项目行按数量显示添加首台／增加摄像头，绑定时锁定当前项目；空设备给接入引导。
3. 紧凑项目表格展示地址、客户、项目状态、摄像头数量、最近监控状态，按需展开设备。移除误导性可播放标签和次要设备字段，解绑收进更多操作。
4. 有意义的分页／权限／过滤／绑定上下文测试、类型检查、构建与本地真实页面浏览器验证。
5. 独立审查。必要数据库变更仅 migration，核实清单并应用、验证 Local/Remote 对齐。不可变候选部署 API＋admin，生产只读验证与回执。

验收：未绑定项目可添加首台；已有项目可追加但不可切换项目；设备详情分页；空态／错误态明确；搜索与筛选重置页码；离线不显示可播放；保留设备管理及现有状态约束。不会在生产创建测试设备绑定。
