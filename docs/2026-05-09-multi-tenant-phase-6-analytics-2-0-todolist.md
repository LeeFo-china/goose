# 多租户改造阶段 6 Todo：分析与数据仓库 2.0

日期：2026-05-09

## 目标

本阶段作为 2.0 规划，不进入 MVP。目标是在多租户业务稳定后，建设平台级和租户级数据分析能力，避免在主业务库上做复杂跨租户实时聚合。

## 前置条件

- 阶段 2 核心隔离稳定。
- 阶段 4 营销和平台线索稳定。
- 阶段 5 平台超管能力稳定。
- 已有明确报表需求和指标口径。

## MVP 阶段约束

MVP 不做：

- 独立分析库。
- 复杂 ETL。
- CDC。
- 实时跨租户大聚合。

MVP 只允许：

- 租户内基于主库索引的统计。
- 平台级关键指标定时汇总表。
