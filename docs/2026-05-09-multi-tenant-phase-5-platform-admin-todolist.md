# 多租户改造阶段 5 Todo：平台超管能力

日期：2026-05-09

## 目标

提供平台运营人员管理租户的能力，包括租户创建、租户管理员创建、租户状态管理、平台线索分配入口和基础用量查看。

## 前置条件

- 阶段 2 完成。
- 阶段 4 平台线索数据模型已确定。
- 平台超管身份模型已确定。
