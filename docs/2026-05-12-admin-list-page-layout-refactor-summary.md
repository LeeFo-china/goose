# Admin 列表页布局整改摘要

日期：2026-05-12

## 目标

后台列表页统一为“页面概览 + 列表 Card”的两段式结构，避免筛选、说明、入口和表格分散在页面多个区域。

## 推荐结构

1. 页面顶部：标题、页面说明、主操作按钮。
2. 指标区：展示当前页面最重要的 3-6 个摘要指标。
3. 列表 Card：
   - `CardHeader`：列表标题、当前筛选摘要、右侧状态 Badge。
   - `CardHeader` 内第二行：筛选条件、搜索框、状态选择。
   - `CardContent`：表格。
   - `CardContent` 底部：分页和总数。

## 客户管理页整改

已将客户管理页调整为：

- 顶部保留客户管理标题和新增客户按钮。
- 指标区展示当前筛选客户、本页有效客户、本页跟进/到店、本页可见号码。
- 删除独立筛选 Card。
- 将客户状态、来源、渠道、跟进状态、关键词搜索放入“客户列表” Card 头部。
- 分页放入客户列表 Card 底部，和表格形成完整列表上下文。

## 后续页面整改原则

- 筛选条件应该放在它作用的列表 Card 内，不应作为页面级独立模块。
- 页面顶部只放概览和关键动作，不放大段筛选表单。
- 列表页不要重复侧边栏入口。
- 指标区只展示对当前业务判断有帮助的数据。
- 表格、筛选、分页应作为一个完整查询上下文出现。

## 可复用页面

后续可按此模式整改：

- 项目管理
- 费用审批
- 员工管理
- 角色管理
- 平台线索
- 平台审计
