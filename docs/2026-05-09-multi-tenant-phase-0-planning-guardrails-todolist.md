# 多租户改造阶段 0 Todo：规划与防护

日期：2026-05-09

## 目标

在不改变现有业务行为的前提下，建立多租户改造边界、风险清单、性能基线和代码防护规则。

本阶段完成后，团队应明确：

- 哪些表必须租户化。
- 哪些接口和异步任务存在跨租户风险。
- 核心接口当前性能基线。
- 后续代码如何避免漏加 `tenant_id`。

## 前置条件

- `main` 分支保持可部署。
- 新建 `feature/multi-tenant` 分支。
- 产品确认多租户 MVP 范围。
- 研发确认不在 `main` 上直接做租户化破坏性改造。
