## 2. Admin 人工回归

### 前置条件

- 需要一个已绑定 `platform_admin` 角色的平台超管员工账号。
- 当前生产库已存在 `platform_admin` 角色，但预检查未发现员工绑定该角色。
- 如需继续平台超管回归，需先指定一个员工账号绑定 `platform_admin`，或创建专用平台超管测试员工。

### 平台超管

- 登录 `https://admin.goodcms.cn/login`。
- 打开 `/platform/tenants`。
- 查看租户列表。
- 创建一个测试租户。
- 确认默认部门、岗位、角色、管理员员工已初始化。
- 打开租户详情页，确认员工数、客户数、项目数等基础统计正常。
- 停用测试租户。
- 用该租户管理员账号登录，确认被拦截。
- 重新启用测试租户。
- 用该租户管理员账号登录，确认恢复正常。

### 租户管理员

- 登录后只能看到本租户客户、项目、员工、费用、验收、摄像头。
- 访问 `/platform/tenants`、`/platform/leads` 应被拒绝。
- 创建客户、项目时，关联数据只出现当前租户数据。

### 平台线索

- 当前生产库 `platform_leads` 暂无数据。
- 需要先通过小程序访客态或后端接口创建一条测试平台线索。
- 打开 `/platform/leads`。
- 创建或选择一条平台线索。
- 分配给目标租户。
- 若目标租户已有同手机号客户，确认显示“老客户新线索”。
- 若目标租户无该手机号客户，确认创建新客户并关联线索。
- 查看审计日志是否记录分配动作。

## 3. 小程序人工回归

### 员工端

- 员工登录后进入所属租户。
- 客户列表只显示当前租户客户。
- 项目列表只显示当前租户项目。
- 项目详情、工序验收、施工日志、摄像头入口正常。
- 尝试打开其它租户项目 ID，应返回无权限或不存在。

### 客户端

- 手机号只命中一个租户时，直接进入该租户客户态。
- 手机号命中多个租户时，进入公司选择页。
- 手机号不命中任何租户时，进入平台访客态或平台线索提交流程。
- 客户选择租户后，项目列表只显示该租户下自己的项目。

### H5 Web-view

- 打开 `https://h5.goodcms.cn/t/{tenantSlug}/p/{slug}`。
- 页面能加载活动配置。
- 提交线索后，线索归属到 URL 中的租户。
- H5 提交后成功态、重复提交态正常。
- 返回小程序按钮行为正常。

## 4. 风险提示

- `feature/multi-tenant` 已接入生产自动部署，后续 push 会触发生产部署。
- `admin.goodcms.cn/api/backend` 是 admin BFF，不是通用 API 入口。
- 小程序和外部系统应优先使用 `https://api.goodcms.cn` 作为后端 API 入口。
