# 阶段 5E 小程序影响说明：平台线索 Admin 页面

日期：2026-05-10

## 结论

本阶段不需要微信小程序端对接。

## 原因

阶段 5E 只新增 admin 端平台超管页面：

- 查看平台线索。
- 手动分配平台线索到租户。
- 查看分配日志和客户去重结果。

小程序端的客户登录、员工登录、访客态平台线索提交、员工分享直绑定、H5 web-view 链路均不变。

## 后续可能需要小程序对接的场景

如果后续要做平台访客态小程序页面，则需要小程序新增：

- 平台访客提交装修需求页面。
- 未命中租户时的公海线索提交链路。
- 已分配租户后的客户入口提示。

这些属于阶段 4/5 的后续增强，不在本阶段范围内。
