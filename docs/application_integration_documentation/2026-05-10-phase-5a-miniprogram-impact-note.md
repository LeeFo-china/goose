# Phase 5A 小程序影响说明

日期：2026-05-10

## 结论

本阶段没有微信小程序端对接工作。

原因：

- 5A 只新增平台超管租户管理 API。
- 不改变客户登录、员工登录、H5 活动页、小程序 web-view、员工分享绑定、平台线索分配链路。
- 小程序端仍按现有租户上下文和分享参数逻辑运行。

## 小程序端暂不需要修改

- 不需要升级 `@gooes/domain`。
- 不需要新增页面。
- 不需要新增接口调用。
- 不需要变更登录态处理。

## 后续可能需要对接的阶段

- 5D：如果后端开始拦截停用租户，小程序端需要展示“公司服务已停用/请联系服务方”的兜底状态。
- 平台访客态页面：如果平台公海获客入口启动，小程序端需要补访客态装修需求提交页。
