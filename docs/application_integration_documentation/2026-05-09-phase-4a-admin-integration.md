# 阶段 4A Admin 对接说明：营销/H5 租户化清点

日期：2026-05-09

## 1. 当前阶段结论

阶段 4A 只完成后端清点和执行拆分，没有改变 admin 接口返回结构，也没有新增页面。

Admin 暂时不需要改代码。

## 2. 后续阶段对 admin 的影响

### 阶段 4B

后端会把营销活动、H5 页面、H5 线索按登录租户隔离。

Admin 端原则：

- 不传 `tenant_id`。
- 不展示 `tenant_id`。
- 继续使用现有接口。
- 项目选择器、活动列表、H5 页面列表、线索列表由后端返回当前租户数据。

### 阶段 4E

平台线索分配会新增平台超管能力，届时 admin 可能新增：

- 平台线索列表页。
- 平台线索分配弹窗。
- 分配记录/审计日志。

### 阶段 4F

员工拓客直绑定会影响租户 admin 的客户详情：

- 客户详情增加“线索来源时间线”。
- 客户列表可能展示“老客户新线索”“平台新线索”标记。

## 3. 当前风险点

- H5 线索转客户当前需要后端改为租户内手机号匹配。
- 营销活动的项目范围必须由后端限制为当前租户项目。
- H5 公开页面仍使用全局 slug，MVP 可接受，但后续建议支持 `/t/:tenantSlug/p/:slug`。

## 4. Admin 验收关注点

阶段 4B 完成后，admin 联调重点是：

- A 租户登录后看不到 B 租户营销活动。
- A 租户登录后看不到 B 租户 H5 页面。
- A 租户登录后看不到 B 租户 H5 线索。
- A 租户不能通过手工 URL 编辑 B 租户 H5 页面。
- 活动包含项目选择器只返回当前租户项目。
