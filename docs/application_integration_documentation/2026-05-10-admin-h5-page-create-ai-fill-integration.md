# Admin 对接说明：新建 H5 活动页 AI 辅助回填

## 1. 背景

admin 后台新建 H5 活动页时，运营人员不一定能直接写出合适的活动标题和描述。

本次新增“AI 辅助生成”能力：

- 用户输入活动要求。
- 后端调用 AI 生成页面标题和页面描述。
- admin 直接回填到现有文本框。
- 用户可继续手动修改。
- 活动路径 `slug` 不由 AI 修改，继续由前端自动随机生成。

## 2. 适用页面

### 2.1 租户后台

入口：

```text
/marketing
```

H5 活动页 tab 中点击：

```text
新建 H5 页面
```

调用接口：

```http
POST /marketing-pages/ai-fill-create
```

### 2.2 平台后台

入口：

```text
/platform/marketing-pages
```

点击：

```text
新建 H5 页面
```

调用接口：

```http
POST /platform/marketing-pages/ai-fill-create
```

## 3. 请求参数

```json
{
  "instruction": "面向郑州老房翻新客户，突出免费量房、限时优惠、预约咨询"
}
```

前端校验：

- 少于 4 个字符时，不请求后端。
- 展示错误：`请输入更具体的活动要求`。

后端仍会做最终校验。

## 4. 响应数据

```json
{
  "title": "老房翻新限时预约",
  "description": "预约免费量房，获取专属翻新方案和活动权益。"
}
```

前端处理：

- `title` 回填到“页面标题”。
- `description` 回填到“页面描述”。
- 不修改：
  - `slug`
  - `display_scene`
  - `sort_order`
  - `start_at`
  - `end_at`
  - 页面默认模块配置

## 5. 交互规则

### 5.1 AI 生成

初始状态：

```text
[活动要求输入框]
[AI 生成]
```

点击 `AI 生成`：

- 按钮 loading。
- 请求后端。
- 成功后直接回填标题和描述。
- toast：`AI 已回填标题和描述，可继续修改`。

### 5.2 重新生成

成功生成后：

```text
[撤销 AI 回填] [重新生成]
```

点击 `重新生成`：

- 使用当前活动要求重新请求。
- 新结果继续覆盖标题和描述。
- 用户仍可修改文本框。

### 5.3 撤销 AI 回填

点击 `撤销 AI 回填`：

- 恢复到本次 AI 回填前的标题和描述。
- 不影响活动路径和其他字段。

### 5.4 手动编辑

AI 回填后，标题和描述仍是普通文本框：

- 用户可继续改。
- 保存/创建时以文本框当前值为准。

## 6. 错误处理

| 场景 | admin 展示 |
| --- | --- |
| 活动要求太短 | `请输入更具体的活动要求` |
| 后端参数校验失败 | 使用后端 `message` |
| AI 配置缺失 | 使用后端 `message` |
| AI provider 异常 | 使用后端 `message` |
| AI 返回格式异常 | 使用后端 `message` |

错误展示在 AI 辅助区域内，不阻塞用户手动填写标题和描述。

## 7. 权限与隔离

### 7.1 租户后台

- 需要 `marketing_page.create` 权限。
- 后端只读取当前租户 H5 活动页作为 AI 上下文。

### 7.2 平台后台

- 需要 `platform_admin`。
- 后端只读取 `tenant_id IS NULL` 的平台 H5 活动页作为 AI 上下文。

## 8. 验收清单

- 租户后台新建 H5 页面弹窗显示 AI 辅助生成区。
- 平台后台新建 H5 页面弹窗显示 AI 辅助生成区。
- 输入活动要求后，AI 能回填标题和描述。
- 回填后可以手动修改标题和描述。
- 重新生成能再次覆盖标题和描述。
- 撤销能恢复 AI 回填前的标题和描述。
- AI 不修改活动路径。
- 活动路径仍自动随机生成。
- 后端权限不足时返回 403，前端展示后端错误。
- AI 失败不影响用户手动创建 H5 活动页。
