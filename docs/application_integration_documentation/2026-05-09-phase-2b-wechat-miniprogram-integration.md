# 阶段 2B 微信小程序对接文档：组织、岗位、角色租户化

日期：2026-05-09

## 变更摘要

阶段 2B 主要影响 admin 后台的组织、岗位、角色和权限配置。小程序端本阶段不需要主动改代码。

## 小程序端请求规则

继续使用现有登录 token。

不要传：

```text
tenant_id
tenantId
X-Tenant-ID
```

租户仍由后端根据登录态识别。

## 可能间接受影响的场景

员工端涉及以下数据时，后端会只返回当前公司数据：

- 项目成员候选员工
- 设计师候选员工
- 监理候选员工
- 员工岗位/角色相关展示

## 错误处理建议

如果小程序端出现：

```text
岗位不存在或未启用
无权限
员工不存在
```

建议提示：

```text
当前账号暂无权限操作该数据
```

并让用户返回上一页或联系管理员。
