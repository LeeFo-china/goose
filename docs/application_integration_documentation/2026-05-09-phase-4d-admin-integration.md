# 阶段 4D Admin 对接说明：客户登录态与租户选择

日期：2026-05-09

## 1. 结论

Admin 端本阶段无需改动。

阶段 4D 主要影响微信小程序客户登录链路，不改变租户 Admin 的客户、项目、日志、验收、营销页面接口。

## 2. 后端新增能力

新增客户侧选择装修公司接口：

```http
POST /customer/auth/select-tenant
```

该接口供小程序客户登录使用，不是 Admin 操作入口。

## 3. Admin 行为保持

以下逻辑不变：

- Admin 客户列表继续按当前员工租户过滤。
- Admin 项目、日志、验收继续按当前员工租户过滤。
- Admin 不需要处理 `platform_visitor`。
- Admin 不需要展示 `select_tenant`。

## 4. 后续 4E 可能影响

阶段 4E 如果开始实现平台公海线索和分配，Admin 或平台后台会新增：

- 平台线索列表。
- 线索分配到租户。
- 老客户新线索标记。
- 客户来源时间线。

这些不属于 4D 范围。
