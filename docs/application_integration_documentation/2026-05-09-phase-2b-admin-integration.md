# 阶段 2B Admin 对接文档：组织、岗位、角色租户化

日期：2026-05-09

## 变更摘要

后台组织、岗位、角色接口已按当前登录员工所属租户隔离。

涉及页面：

- 组织架构
- 岗位管理
- 角色管理
- 权限配置
- 员工创建 / 编辑
- 项目成员候选员工选择

## Admin 前端是否需要传 tenant_id

不需要。

前端继续使用现有接口，后端根据登录 token 自动识别租户。

请不要新增：

```text
tenant_id
tenantId
X-Tenant-ID
```

## 行为变化

### 部门

- 部门列表只返回当前公司部门。
- 创建部门自动归属当前公司。
- 部门编码从平台全局唯一调整为公司内唯一。

### 岗位

- 岗位列表只返回当前公司岗位。
- 创建岗位自动归属当前公司。
- 岗位编码、岗位名称从平台全局唯一调整为公司内唯一。

### 角色

- 角色列表只返回当前公司角色。
- 创建角色自动归属当前公司。
- 角色编码从平台全局唯一调整为公司内唯一。
- 给员工分配角色时，只能分配当前公司角色。

### 规则配置

- 部门可选岗位规则按当前公司读取和保存。
- 项目成员角色可选岗位规则按当前公司读取和保存。

## 前端注意点

- 原页面无需增加租户选择器。
- 如果切换账号后看到的部门/岗位/角色数量不同，这是预期行为。
- “编码重复”现在指当前公司内重复，不代表平台全局重复。
- 如果接口返回 403，按无权限处理。

## 联调重点

- A 公司创建岗位编码 `PROJECT_MANAGER` 后，B 公司也应允许创建同编码岗位。
- A 公司员工编辑时，部门和岗位下拉只出现 A 公司数据。
- A 公司角色列表不出现 B 公司角色。
- A 公司不能把 B 公司角色分配给 A 公司员工。
