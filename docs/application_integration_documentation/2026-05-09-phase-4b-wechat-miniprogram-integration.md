# 阶段 4B 小程序/H5 对接说明：营销/H5 基础租户隔离

日期：2026-05-09

## 1. 结论

阶段 4B 主要是后端隔离，小程序端暂时不需要改代码。

H5 公开提交线索和埋点已经由后端从页面 slug 反推出 `tenant_id`，小程序和 H5 前端不需要传 `tenant_id`。

## 2. 当前兼容行为

继续支持：

```text
https://h5.goodcms.cn/p/:slug
```

继续支持：

- H5 页面详情读取。
- H5 表单提交。
- H5 埋点提交。
- H5 已提交本地状态。

## 3. 后端行为变化

- H5 表单提交后，线索会写入页面所属租户。
- H5 表单 24 小时去重按 `tenant_id + page_id + phone` 生效。
- 同一个手机号允许在不同装修公司的 H5 页面分别提交线索。
- H5 线索后续转客户时，只会在对应装修公司内匹配手机号。

## 4. 小程序暂不需要处理

- 不需要传 `tenant_id`。
- 不需要解析租户。
- 不需要改变 web-view 地址。
- 不需要改变表单提交参数。

## 5. 下一阶段可能需要对接

阶段 4C 预计会涉及：

- H5 session token 增加租户信息。
- 小程序活动列表按客户/员工当前租户返回。
- 可能新增租户化 H5 路由：

```text
/t/:tenantSlug/p/:slug
```

阶段 4D 预计会涉及：

- 客户登录返回 `platform_visitor`。
- 客户登录返回 `select_tenant`。
- 小程序增加平台访客页和装修公司选择页。
