# 阶段 3G 微信小程序对接说明：AI Provider 与场景路由

日期：2026-05-09

## 1. 小程序是否需要改动

本阶段小程序端不需要改代码。

原因：

- 后端接口路径不变。
- 请求参数不变。
- 返回结构保持兼容。
- AI provider、model、token 统计都在后端网关层处理。

## 2. 受影响但无需改造的能力

小程序端如果已经对接以下能力，可以继续按原方式调用：

- 自媒体短视频文案识别和脚本生成。
- 装修问答非流式接口。
- 客户施工日志分享文案。

## 3. 租户归因说明

后端会在可识别租户的场景里自动写入 `ai_call_logs.tenant_id`。

短视频脚本生成链路：

1. 小程序创建短视频转写任务。
2. 后端在任务上记录当前租户。
3. 转写完成后生成脚本。
4. 脚本生成调用 AI 时，后端把任务租户写入 `ai_call_logs`。

小程序端不需要额外传 `tenant_id`。

## 4. 用户体验建议

由于 AI provider 可能失败或切换 fallback，小程序端应继续保持已有异步任务体验：

- 任务处理中展示 loading 或处理中状态。
- 失败时展示后端返回的失败原因。
- 不要无限等待，继续使用轮询超时和失败态。

## 5. 后续可能需要小程序配合的内容

如果后续新增“AI 用量展示”或“租户 AI 套餐额度”，小程序端可能需要新增：

- AI 用量查询页面。
- 剩余额度提示。
- 额度不足时的引导文案。

当前 3G 阶段不包含这些交互。
