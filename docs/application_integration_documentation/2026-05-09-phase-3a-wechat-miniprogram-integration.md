# 阶段 3A 微信小程序对接说明：费用审批与任务中心租户隔离

日期：2026-05-09

## 结论

小程序端本阶段无需改接口参数。员工登录后，后端根据登录态中的租户上下文自动过滤费用申请和任务中心待办。

## 受影响入口

- 员工端费用申请列表
- 员工端费用申请详情
- 员工端费用申请创建、提交、审批、驳回、打款
- 员工端任务中心 / 今日待办

## 行为变化

### 费用申请

- `GET /expense-requests` 只返回当前员工所属租户的费用申请。
- `GET /expense-requests/:id` 访问其他租户单据会返回不存在或无权限。
- `POST /expense-requests` 不需要传 `tenant_id`，后端自动写入。
- 费用申请关联项目必须属于当前租户。
- 审批候选人接口只返回当前租户员工。

### 任务中心

- `GET /task-center/todos`
- `GET /task-center/todos/summary`

返回结果只包含当前租户数据：

- 客户跟进待办
- 项目日志待办
- 费用审批待办

## 小程序端建议

- 不要在请求体或 query 中传 `tenant_id`。
- 如果小程序端本地缓存了费用分类，员工切换账号后必须清空缓存并重新拉取。
- 如果出现“列表为空”，优先检查当前登录员工是否属于正确租户，以及是否拥有费用/任务中心权限。

## 联调检查

- A 租户员工不能看到 B 租户费用申请。
- A 租户员工不能审批 B 租户费用申请。
- A 租户员工任务中心不能出现 B 租户客户跟进、项目日志和费用待办。
- 审批候选人搜索结果不能出现其他租户员工。
