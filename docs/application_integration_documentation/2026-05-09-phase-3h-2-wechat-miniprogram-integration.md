# 阶段 3H-2 微信小程序对接说明：双租户验收

日期：2026-05-09

## 1. 小程序是否需要改动

本阶段小程序端不需要改代码。

3H-2 的目标是验证后端阶段 3 业务模块的租户隔离，不改变小程序接口。

## 2. 小程序联调关注点

小程序端后续联调时重点观察：

- A 租户客户不应看到 B 租户项目日志。
- A 租户客户不应打开 B 租户工序验收详情。
- 员工端任务中心不应出现其他租户的验收、费用、日志待办。
- 短视频识别任务和脚本历史只应展示当前租户/当前用户可见数据。

## 3. 推荐处理

如果后端返回 `400/403/404`：

- 小程序应展示“内容不存在或无权访问”。
- 不要重试切换到其他租户。
- 不要把其他租户资源 ID 缓存在本地继续使用。

## 4. 当前结论

3H-2 没有新增小程序字段和接口。小程序只需要保持现有错误态处理即可。
