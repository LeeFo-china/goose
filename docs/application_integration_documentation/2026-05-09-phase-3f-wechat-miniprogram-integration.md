# 阶段 3F 微信小程序对接说明：系统配置分层

日期：2026-05-09

## 结论

小程序端无需调整。系统配置分层是后端和 Admin 侧能力，小程序继续按现有业务接口调用。

## 对小程序的影响

- 小程序不需要传 `tenant_id`。
- 微信 AppID / Secret、短视频识别、腾讯云 ASR、摄像头 SIP 等仍由平台级配置提供。
- 后续如果租户配置了短信签名、H5 品牌色、Logo 等，业务接口可以在后端读取租户覆盖配置后返回给小程序。
- 当前阶段没有新增小程序接口字段。

## 需要关注的场景

### 短信相关

- 发送短信时，后端仍可以读取平台级短信网关和模板 Code。
- 租户短信签名 `ALIYUN_SMS_SIGN_NAME` 已支持租户覆盖。
- 项目验收短信已接入业务租户，会优先使用租户签名，再回退平台签名。
- 登录验证码、客户绑定验证码等无明确租户上下文的短信仍使用平台级签名。

### H5 / 品牌展示

- H5 品牌色、Logo、租户文案偏好只预留规则，当前未新增字段。
- 小程序端暂不需要读取这些配置。

## 小程序端建议

- 不要新增 `tenant_id` 参数。
- 不要在小程序端缓存平台级配置。
- 后续如增加“租户品牌配置接口”，再由后端返回具体字段，小程序只消费业务接口结果。

## 联调检查

- 小程序现有登录、短信、摄像头、短视频识别链路不受影响。
- 租户管理员改短信签名后，如果后端业务服务接入 `tenantId` 读取，短信签名可按租户生效。
- 未配置租户签名时，后端回退平台默认签名。
