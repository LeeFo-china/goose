## Task 11 设计读法

Reading this as: 面向装修企业经营者的多页 B2B 官网，采用“施工现场纪实 + 清晰业务台账”的品牌语言，延续鹅班长黄黑识别与 shadcn 交互基础。

- `DESIGN_VARIANCE: 7`：页面使用不对称图文、流程带和横向能力索引，避免模板化三等分卡片。
- `MOTION_INTENSITY: 4`：只使用 CSS 进入过渡与交互反馈，并为 reduced motion 提供静态回退。
- `VISUAL_DENSITY: 4`：一屏一个主要结论，保留装修业务所需的信息密度。
- 场景：装企负责人或项目经理在办公室及工地间查看官网，环境光明暗不固定，因此沿用系统浅色与深色主题。
- 字体与色彩：沿用已提交的 Avenir Next、苹方与微软雅黑字体栈，以及鹅班长黄黑语义色，不创建第二套品牌系统。
- 图片策略：施工纪实照片承担真实业务语境，页面 HTML 承担全部标题、说明与 CTA；图片内不放文字、Logo 或伪产品界面。
