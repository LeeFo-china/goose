# AI 供应商主从工作区设计

**日期：** 2026-09-12

**范围：** 平台 Admin「AI 模型路由」页面的供应商 Tab。仅调整前端信息架构和呈现，不修改 API、数据库、权限或模型运行逻辑。

## 1. 目标

供应商 Tab 使用明确的主从工作区：左侧选择供应商，右侧只展示当前选中供应商的连接配置和模型列表。切换供应商时整体替换右侧内容，不把多个供应商配置连续堆叠在同一内容区。

## 2. 设计方向

Reading this as：平台管理后台的高频配置工作区，使用清晰、稳重的大块面板布局。

- `DESIGN_VARIANCE: 3`
- `MOTION_INTENSITY: 2`
- `VISUAL_DENSITY: 6`
- 继续使用现有 Next.js、shadcn/Radix、Tailwind 和好店智装云 Admin 设计令牌。
- 深蓝色用于当前选择、主要操作和焦点；白色及冷中性色承载内容；不增加渐变、玻璃效果或装饰动画。

## 3. 桌面布局

整个供应商 Tab 使用一个双栏工作区：

1. 左栏固定约 300 至 320 像素，包含供应商标题、新增按钮、分页列表和加载、错误、空状态。
2. 供应商列表项显示名称和启停状态，当前项使用清晰的选中背景、边框或文字权重，不只依赖颜色。
3. 右栏只挂载一个供应商详情工作区，禁止对供应商数组执行详情区域的逐项渲染。
4. 右栏使用一个占据剩余宽度的大 Card。Card 顶部显示当前供应商名称、状态和只读系统编码。
5. 大 Card 内依次显示“连接配置”和“模型列表”，通过区块标题、稳定间距和单条分隔线区分，不再嵌套同等级 Card。
6. 模型列表必须始终以当前供应商 ID 查询和写入。切换供应商时清空旧供应商的临时状态，迟到响应不得覆盖当前内容。

## 4. 新建和切换行为

- 点击左侧供应商：更新唯一选中 ID，右侧整体切换为该供应商内容。
- 点击“新增供应商”：进入独立新建状态，右侧显示空白连接表单；供应商保存成功后自动选中新记录并显示它的模型列表。
- 删除当前供应商成功：选择当前页第一条其他记录；若当前页没有其他记录，进入空白新建状态。
- 分页或刷新不主动重写 `selectedId`；当前页未包含当前记录但 `providers` 缓存仍包含时，保留跨页编辑上下文。
- 保存、验证、删除及模型操作期间保持现有权限和并发版本保护。

## 5. 移动端布局

- 小于 `xl` 时变为单列，上方为供应商选择区，下方为单个供应商详情 Card。
- 供应商列表保持有界高度和自身滚动，不让多个详情内容进入页面。
- 连接表单和模型表格按现有响应式规则换行或局部横向滚动，按钮文字不得换行，字段标签始终位于输入框上方。

## 6. 状态与无障碍

- 加载：左栏使用与列表项尺寸一致的 Skeleton；右栏在选择变化期间保留结构并显示局部加载状态。
- 空状态：没有供应商时说明可新增连接配置；无管理权限时只显示事实性只读说明。
- 错误：供应商列表、连接配置和模型列表的错误分别就近显示，重试只影响失败区块。
- 焦点：切换供应商后不强制抢焦点；新建、保存和删除完成后恢复到可预测的操作入口。
- 使用语义按钮、`aria-pressed` 或等价选中语义，并保持键盘操作与可见焦点环。

## 7. 验收标准

1. 任意时刻右侧最多存在一个供应商编辑器和一个对应模型列表。
2. 点击不同供应商后，右侧名称、连接字段和模型请求均切换到同一个供应商 ID。
3. 快速切换时，迟到的连接或模型响应不能覆盖当前供应商。
4. 新建状态不显示旧供应商模型；保存后自动进入新供应商详情。
5. 1440 像素桌面和 400 像素窄屏无页面级横向溢出。
6. 只读、加载、空、错误、删除冲突和版本冲突状态保持可操作且信息明确。
7. Admin 组件测试、类型检查和 AI 模型路由 Playwright 回归全部通过。

## 8. 非目标

- 不新增或修改供应商、模型、路由 API。
- 不修改数据库 migration。
- 不改变真实密钥输入、加密和回显规则。
- 不改变场景路由 Tab。
- 不引入新的 UI 或动画依赖。
