# 公司侧 Admin 文案设计

日期：2026-09-22

## 目标

公司员工使用 Admin 时，不再看到“租户”这一内部技术术语，统一使用“公司”。概览页标题由“租户概览”改为“公司概览”。

## 范围

- 修改公司侧路由及公司侧复用组件中的用户可见中文文案。
- 包含标题、说明、按钮、标签、占位文字、提示、空状态和面向用户的错误兜底。
- 平台超管页面继续使用“租户”，以准确表达平台管理多个独立公司的关系。
- 不修改 `tenant` 变量、类型、组件名、接口路径、权限码、API 响应字段、数据库字段或测试夹具中的技术标识。

## 文案规则

- “租户概览”改为“公司概览”。
- “当前租户”“本租户”分别改为“当前公司”“本公司”。
- “租户后台”“租户管理员”“租户员工”分别改为“公司后台”“公司管理员”“公司员工”。
- “租户私有”“租户自有”“租户默认”等公司侧表述分别改为“公司私有”“公司自有”“公司默认”。
- 同一复用组件若同时服务平台超管和公司员工，应按实际模式选择文案，不能破坏平台语义。

## 验收

- 公司侧可达页面的用户可见文本不再出现“租户”。
- 平台超管页面的“租户管理”“目标租户”等平台术语保持不变。
- Admin 静态检查和生产构建通过。
