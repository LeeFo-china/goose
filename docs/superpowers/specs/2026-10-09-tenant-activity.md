# 租户活跃概览（已获用户同意按推荐推进）

目的：协助超管判断租户是否开始使用、团队采用程度、持续使用与业务使用。登录次数是辅助信息，不做缺依据的活跃评分。

首期范围：现有分页租户列表增加近7日使用摘要；详情增加近7日登录次数与5类业务动作。固定北京时间，窗口含今天近7日。近30日趋势留待后续。活跃=主动浏览或成功业务操作，登录本身单独计数，不等于有效使用。总活跃员工以租户内 employee_id 跨端去重；端内分别去重。当天多次使用只计1活跃天。

采集：后台成功登录；小程序明确交互登录（手机号验证直接进入员工/选择员工身份、旧verify-role），排除自动getOpenId、客户/访客、平台员工、失败请求。后台主动导航（可见页面）调用窄范围view接口；小程序同接口交接给其团队，不修改orange，并说明尚未采集浏览。成功业务写入：新客户、跟进、项目、施工日志、员工处理验收；后端按明确路由和资源证据记录，拒绝自动请求/未知来源。只信认证身份与token渠道，不信客户端提交租户/员工/渠道。

数据：migration创建受保护采集配置、幂等事件凭据、每日员工/渠道汇总和租户最后使用记录。事件只存ID和动作，无电话/IP/token/客户详情。服务角色RPC写入，所有表RLS，无匿名/普通authenticated写入。读取单次RPC批量最多100租户、只扫描近7日汇总，返回采集起点；上线前历史不补造。采集失败不得使已成功业务失败，记录结构化告警；读取失败显式unavailable，不当0。

客户端：复用shadcn与现有租户组件，一列使用摘要，详情平铺section无多重card；显示未采集/采集中/统计暂不可用；采集不足7天时提示起点。小程序浏览未接入的覆盖范围提示始终保留，不能夸称完整覆盖。

本轮不默认部署生产；先完成代码、migration隔离验证、API/Admin检查、视觉验收和评审，交付可发布结果。
