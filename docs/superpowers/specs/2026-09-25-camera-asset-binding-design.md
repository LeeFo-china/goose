# 摄像头设备资产与项目绑定设计

## 目标

把物理设备、云端接入标识和项目内展示名称分开管理：设备管理登记机身 SN 并验证视频，项目摄像头从未绑定设备中选择并设置“客厅”等别名。

## 领域模型

- `hardware_serial`：用户从设备标签录入的机身 SN，用于识别物理设备；根资产按公司、厂商、SN 唯一，同一物理设备的通道继承该 SN。
- `vendor_device_serial`：第三方平台设备主 ID；腾讯云场景为 DeviceId，继续由后端维护。
- `vendor_channel_id`：可播放通道 ID。IPC 通常一个通道，NVR 可以多个通道。
- `project_cameras.name`：绑定项目后的业务别名，例如“客厅”。

旧设备无法可靠反推出机身 SN，不用腾讯云 DeviceId 冒充；显示“未登记 SN”并允许补录。

## 用户流程

### 设备管理

1. 点击“登记设备”。
2. 输入设备 SN，设备类型默认 IPC；密码留空由后端生成。
3. 后端创建腾讯云设备资产并返回 GB28181 接入参数，不绑定项目。
4. 设备保存配置并联网后同步通道。
5. 列表显示 SN、在线状态、绑定项目和操作。已绑定显示项目名称，未绑定显示“未绑定”。
6. 每个已有可播放通道的设备都支持预览；NVR 先选择通道。待接入、无通道或离线设备给出明确不可预览原因。

### 项目摄像头

1. 页面保留一个全局“添加摄像头”入口；项目行也可用项目上下文打开同一绑定表单。
2. 全局入口先选择任意有权限且允许绑定的项目。
3. 绑定表单只展示未绑定、已同步出通道的公司设备资产。
4. 用户选择设备并填写项目内别名。
5. 高级设置默认收起，包含客户可见、控制权限、能力、播放协议、加密、排序和备注。
6. 后端按设备资产 ID 解析第三方标识并再次校验租户归属和未绑定状态；并发重复绑定返回 409。

## API

- `POST /tenant-devices/tencent`：登记腾讯云设备，输入 `hardware_serial`、`device_type` 和可选密码。
- `GET /tenant-devices`：分页返回结构化 `source_project`、`bound_project`、`bound_camera` 摘要。
- `POST /tenant-devices/:id/play-params`：租户范围内预览设备通道，不要求先绑定项目。
- `POST /projects/:projectId/cameras`：兼容现有请求，并新增以 `tenant_device_id` 绑定的安全路径。

## 数据与安全

- migration 新增 `tenant_devices.hardware_serial` 和部分唯一索引。
- 设备列表和关联摘要保持分页，项目与摄像头通过批量查询补全，禁止 N+1。
- 播放接口校验当前公司与 `project.read` 权限；腾讯设备只允许已同步通道资产，萤石设备复用现有 EZPlayer 播放参数。
- 接入密码响应保持 `private, no-store`；列表不返回密码。

## 验收

- 公司已有摄像头时，仍能选择任意零摄像头项目。
- 新登记 SN 不自动绑定项目，重复 SN 返回 409。
- 项目只能选择未绑定通道，绑定别名后列表显示项目名和别名。
- 解绑后设备重新显示为未绑定，可分配到其他项目。
- 已绑定和未绑定通道都能预览；待接入、无通道、离线状态提示准确。
- NVR 多通道分别显示绑定项目并可逐通道预览。
