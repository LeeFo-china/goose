# 抖音客户项目登录提示优化设计

## 背景

0.1.36 审核版在 iPhone 抖音真机中已验证：免费量房申请页能够成功获取抖音绑定手机号，说明手机号能力、公私钥配置和生产换号链路可用。

客户登录页使用同一授权能力取得手机号后，如果该手机号没有关联后端客户项目，后端会返回 `CUSTOMER_CONTEXT_MISSING`。当前页面把所有认证异常统一覆盖为“客户登录失败，请重试”，导致用户和审核人员容易把正常的业务未匹配结果误解为抖音手机号能力故障。

## 目标

- 明确该页面登录的是装修公司的客户项目，而不是抖音账号。
- 对“手机号授权成功，但未关联客户项目”给出准确、可行动的提示。
- 保留未知错误和网络错误的安全兜底，不直接透传任意服务端消息。
- 抖音手机号授权和短信验证码两种方式使用一致的客户项目匹配提示。

## 错误处理

客户端按稳定错误码处理预期业务结果，不直接展示所有服务端错误消息：

- `CUSTOMER_CONTEXT_MISSING`：显示“未找到关联项目。该手机号尚未关联装修项目，请联系装修公司确认预留手机号。”
- 抖音手机号回调没有返回授权令牌：继续使用现有回调分类提示，并展开短信验证码入口。
- 网络、超时、无效响应、未知服务端错误：显示“登录客户项目失败，请稍后重试”。
- 身份选择失败：保留候选项目列表，并显示现有身份选择失败提示。

未关联项目时不自动展开短信验证码表单。相同手机号改用短信验证码不会产生不同的匹配结果；用户如需尝试装修公司登记的其他手机号，可主动点击“使用其他手机号登录项目”。

## 实现边界

- 仅修改 `apps/douyin-mini` 客户登录页面和对应测试。
- 后端已经返回稳定的 `CUSTOMER_CONTEXT_MISSING`，不修改 API、数据库或错误协议。
- 不改动手机号授权组件、密钥、会话启动和防过期机制。
- 不改动 `/Users/leefo/Public/work/orange`。

## 验收

1. 未关联手机号完成抖音授权后，页面显示“未找到关联项目”及联系装修公司的指引。
2. 已关联单个客户项目时正常进入项目列表。
3. 已关联多个客户身份时正常进入装修公司选择状态。
4. 短信验证码登录遇到未关联手机号时显示同一提示。
5. 网络或未知错误仍显示通用提示，不泄露内部错误信息。
6. 页面所有主要文案均明确指向“客户项目”，不会被理解成登录抖音账号。

## 提审说明

提审备注写明：手机号授权用于匹配装修公司已登记的客户项目。若审核手机号尚未登记，页面会明确提示“未找到关联项目”；这表示手机号授权成功，但暂无关联装修项目。
