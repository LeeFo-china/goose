# 抖音小程序工作台简化设计

租户管理员打开工作台后，先看到授权和版本状态，再看到当前可执行的操作。后续信息按提审问题、公开资料、公开内容、手机号留资、最近版本排列，各区块用留白和分隔线组织，不再用总览卡片包裹其他卡片。

当前体验、提审、同步和发布动作继续使用现有状态策略、权限和接口；二维码在动作附近保留，已提交审核后仍可看到体验二维码。提审就绪时只显示简短结果，有阻断时逐项给出原因和现有管理入口。公开资料区分内部租户名称与访客可见品牌，公开内容保留案例、工地和服务区域计数。手机号留资保留开关、AppID、保存、只读及授权失效提示。

视觉沿用后台已有文字、颜色和按钮组件。工作台内容放在一张无边框的白色页面底板上，不再使用总览卡片或重复边框容器；信息用标题、次要文本和水平分隔线建立层次。小屏时操作和资料纵向排列，状态与按钮换行，长品牌名称可断行。

验收以现有组件测试、Admin 类型检查和静态渲染结构检查为主；本次不改变服务端协议或权限规则。
