# Workflow React Flow + ELK Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 admin 流程编排画布完整迁移到 React Flow + ELK，并删除旧自研画布代码。

**Architecture:** React Flow 成为唯一画布引擎，负责节点渲染、拖拽、缩放、平移、连接和边渲染。ELK 只负责一键整理，布局结果写回现有业务节点坐标和分支节点投影坐标。后端接口和业务图结构保持不变。

**Tech Stack:** Next.js 15, React 19, TypeScript, Tailwind, `@xyflow/react`, `elkjs`, Playwright.
