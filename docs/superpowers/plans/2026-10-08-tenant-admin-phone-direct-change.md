# 超管直接变更租户管理员登录手机号

用户明确修正上一版要求：超管换号不需要验证码。本次按此规则直接实施，正常登录验证规则不变。

## 设计

沿用租户详情的当前管理员入口，只填写新号码、变更原因并确认管理员本人未变更。删除短信发送、验证码输入和倒计时。仅新鲜有效的平台超管会话可操作。

确认接口仍为 `/platform/tenants/:id/admins/:employeeId/phone-change/confirm`，请求仅含 `new_phone, expected_version, reason, same_person_confirmed, idempotency_key`。旧发送接口返回 410 提示刷新页面，不再发送短信。后端不创建或自动通过短信挑战，也不依赖免验证码环境变量。

新增 migration 定义独立直接换号 RPC，复用已有超管校验、目标员工锁、号码锁、号码保护和凭证版本触发器。号码变更与审计原子提交，审计标记 `authorization_method=platform_superadmin`；相同请求幂等返回，修改内容拒绝。保留旧迁移、历史短信和审计记录，不修改员工身份、角色及微信绑定。
