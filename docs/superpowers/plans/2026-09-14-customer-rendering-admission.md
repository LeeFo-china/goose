# 客户生图：输入审核与原子任务准入

目标：在既有私有上传与额度账本上，增加可恢复的内容审核和同事务任务/次数/租户预算预占。新任务默认关闭；本计划不开放客户生成入口，也不提交模型任务。

1. 为 `customer_rendering_inputs` 增加审核租约、下次审核时间、审核结论及时间；迁移创建索引。写审核 worker 的失败用例，再实现有界扫描、租约 claim、COS CI 私有对象审核、确定性结论更新。结果 `0` 才批准，`1` 拒绝，`2` 或未知结果保持待审核并进入人工处理；传输失败按退避重试。审核不可用时输入不能进入任务。
2. 迁移新增默认关闭的租户生图设置和任务表；原子 RPC 在一笔事务中校验已发布素材、同主体已批准图片、日任务数、按单任务预留的日预算及现有额度预占。重放先按主体与幂等键返回原任务；不同请求报冲突。用行锁串行化同租户准入。预算默认未配置，因此不会意外产生付费任务。
3. API 双端 `POST /jobs` 使用共享 DTO，controller 只校验和包装响应，service 解析可信主体、HMAC 和请求摘要，repository 唯一调用原子 RPC。返回任务 ID、queued 状态和额度快照。测试覆盖归属、重放、预算/次数阻断和 RPC 返回异常。
4. 验证：先运行相关 Bun 测试与 API 类型检查，再运行迁移静态校验；若本地 Supabase 可用，在隔离数据库执行迁移并检查 migration list。生产迁移与服务开关另按发布门禁处理。

回滚：先关闭审核 worker 与新任务入口；已写入的任务和额度账本保留对账。数据库结构如需回退，通过后续 forward migration 修正，不能删除历史任务或预占记录。
